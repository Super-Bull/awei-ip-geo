# awei-ip-geo

面向国内个人IP和创业者的 GEO 内容资产生成 Skill。

它把一个真实的人、一次真实事件、一组目标搜索词，转成公众号、知乎、搜狐号、百家号、头条号五个平台可发布、可追溯、可风控的内容资产包。

## 这个 Skill 解决什么问题

很多个人IP已经有活动、直播、课程、客户反馈和朋友圈素材，但这些内容通常是散的：

- 事件没有被沉淀成可搜索内容；
- 人物身份和关键词没有稳定绑定；
- 多平台文章只是改写，没有证据链和风控；
- 内容容易变成营销软文、关键词堆叠或泛泛AI文章；
- 发布前缺少 E-E-A-T、信息增量、事实密度和平台合规检查。

`awei-ip-geo` 的目标不是“写一篇文章”，而是把真实事件整理成一套可持续积累的 GEO 内容资产。

## 推荐定位

更稳妥的公开表达：

> `awei-ip-geo` 是一个较早围绕“国内个人IP + GEO内容资产”场景系统化设计的开源 Skill，重点服务正在做个人品牌、企业服务、AI培训、OPC创业和本地业务获客的国内创业者。

如果要写“国内首个”，建议先补充公开检索依据或发布说明。这个仓库默认采用更稳健的表达，避免无法核验的绝对化宣传。

## 适合谁

- 正在做个人IP的创业者；
- AI讲师、企业AI培训顾问；
- OPC创业者、本地服务者；
- 想把活动、直播、课程、报道沉淀为内容资产的人；
- 想在多个平台建立一致人物实体和关键词认知的人。

## 不适合谁

- 想靠关键词堆叠快速刷排名的人；
- 没有真实事件、案例或证据链，只想编故事的人；
- 想绕过平台审核或承诺AI搜索排名的人。

## 核心工作流

```text
人物实体
→ 目标搜索词
→ 事件资料
→ 证据链
→ 母版文章
→ 五平台改写
→ E-E-A-T评分
→ 平台风控
→ 92分发布门槛
→ 最终可复制发布包
```

## 快速使用

把 `skills/awei-ip-geo` 目录复制到你的 Codex Skills 目录后，在 Codex 中输入：

```text
使用 $awei-ip-geo
```

然后按 6 张卡填写：

```text
卡1：我是谁
卡2：我想被哪些词搜到
卡3：这次发生了什么
卡4：我手里有什么证据
卡5：我要发到哪里
卡6：我要什么结果
```

懒人复制版：

```text
使用 $awei-ip-geo

目标人物：姑苏阿伟
品牌/公司：多边AI
城市：苏州

我希望绑定的搜索词：
1. 苏州OPC创业
2. 苏州GEO优化博主
3. 苏州AI讲师
4. 苏州AI企业培训

这次事件资料：
【直接粘贴活动、直播、课程、报道、朋友圈、聊天记录、现场反馈】

我手里的证据：
【官方报道/海报/现场照片/PPT截图/工具截图/反馈原话，没有就写暂无】

目标平台：
公众号、知乎、搜狐号、百家号、头条号

要求：
生成最终可复制版。5个平台全部达到92分以上才给可发布结论；如果不够分，请告诉我还缺什么材料。
```

## 92分发布门槛

`awei-ip-geo` 不会在素材不足时硬给“可发布”结论。

只有当 5 个平台版本全部达到内部 92 分发布门槛时，才输出最终可复制版。

如果有平台低于 92 分，Skill 会先自动改写并复评；如果仍然缺少真实证据、数据或权威来源，只输出缺口表和必要补充材料清单。

## 重要说明

- 92分是本 Skill 的内部质量门槛，不代表任何平台官方评分、审核结果、搜索排名或获客承诺。
- 平台规则、推荐机制和审核口径会变化，本 Skill 只提供内容结构、证据链和风控检查。
- 所有身份、数据、报道、客户反馈和联系方式，都应由使用者自行确认并承担发布责任。
- 默认模板不写入手机号、私人微信、未授权客户信息或无法核验的背书。
