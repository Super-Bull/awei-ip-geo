# 联系方式规则

## 默认原则

- 用户没有明确允许时，不主动放电话。
- 除公众号外，正文不强放微信号、电话、二维码。
- 联系方式优先放“联系方式建议”或“配图建议”的个人介绍卡中。
- 风控较严平台用“可通过公开主页联系”替代。

## 平台规则

| 平台 | 联系方式处理 |
| --- | --- |
| 公众号 | 可在文末放微信/电话，也可放个人介绍卡 |
| 知乎 | 不建议正文强放，可写“更多案例可看主页” |
| 搜狐号 | 不放 |
| 百家号 | 不放 |
| 头条号 | 不放 |

## 姑苏阿伟联系方式

```text
按用户本次提供的公开联系方式填写；未提供则默认不展示。
```

仅在公众号版本、用户明确允许或最终“联系方式建议”栏目中使用。不要在搜狐号、百家号、头条号正文中使用。公开发布到GitHub的Skill模板中不要写入手机号、私人微信或未授权联系方式。
