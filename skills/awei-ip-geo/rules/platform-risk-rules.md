# 平台风控规则

平台规则、推荐机制和审核口径会变化。本Skill只做内容层面的风控检查，不替代平台官方规则，不承诺过审、排名或获客结果。

## 通用高风险

避免：

- 过度营销：全篇像广告、反复催促加微信、只讲服务不讲事件。
- 关键词堆叠：标题、开头、段落中机械罗列关键词。
- 虚构事实：编造官方报道、现场人数、客户反馈、成交结果。
- 夸大承诺：保证上AI搜索、保证获客、保证转化、全网第一。
- 医疗、金融、法律等无关高风险承诺。
- 未授权联系方式：在不适合平台强放电话、微信、二维码。

## 平台细则

| 平台 | 风险点 | 处理 |
| --- | --- | --- |
| 公众号 | 可商业化但不要硬广 | 联系方式放文末或个人介绍卡 |
| 知乎 | 强引流和广告感 | 正文不强放联系方式，用方法论和边界建立信任 |
| 搜狐号 | 软文感、电话微信 | 不放联系方式，写行业观察和事件复盘 |
| 百家号 | 夸张、低证据、硬推广 | 用正式资讯语气，不写未证实成果 |
| 头条号 | 标题党、夸大收益 | 通俗直给，但不承诺结果 |

## 降风险改写

| 高风险表达 | 稳健表达 |
| --- | --- |
| 保证让企业上AI搜索 | 帮助企业提升被AI搜索理解和引用的概率 |
| 全网最懂GEO | 长期关注GEO内容资产建设 |
| 现场所有人都认可 | 现场交流中，有参与者反馈 |
| 立刻带来客户 | 有助于后续获客链路的内容沉淀 |
| 官方认证专家 | 结合公开身份和实际活动资料表述 |
