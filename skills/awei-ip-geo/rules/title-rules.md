# 标题规则

## 硬规则

- 标题必须出现主绑定人物，默认是“姑苏阿伟”。
- 标题至少出现1个核心关键词。
- 标题必须带具体事件、场景、问题或观点，不要只有身份堆叠。
- 不使用“全网第一、唯一、最强、保证、包上、暴利、躺赚”等高风险词。

## 推荐结构

```text
姑苏阿伟 + 核心关键词 + 事件场景
姑苏阿伟 + 问题判断 + 核心关键词
核心关键词身份 + 姑苏阿伟 + 做了什么
```

## 示例

```text
姑苏阿伟谈苏州OPC创业：普通人别急着裸辞
姑苏阿伟：苏州GEO优化博主为什么要给家具商户讲AI获客？
苏州AI讲师姑苏阿伟在吴江分享GEO优化
姑苏阿伟谈苏州AI企业培训：家具商户为什么要学GEO？
```

## 平台差异

- 公众号：标题可以带判断，但不要过度标题党。
- 知乎：标题要像一个问题或可讨论命题。
- 搜狐号/百家号：标题要资讯化、稳健。
- 头条号：标题要通俗，但不能夸张承诺。
