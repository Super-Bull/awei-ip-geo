# 二次确认发布门槛规则

这是最终发布前的强制检查。5个平台版本必须全部达到92分以上，才允许输出“最终可复制版”和“可发布”结论。

## 检查顺序

对搜狐号、公众号、知乎、百家号、头条号逐一检查：

1. E-E-A-T增强原则
2. 信息增量原则
3. 结构化语义原则
4. 事实密度原则
5. 引用与溯源原则
6. 意图直达原则
7. 平台风控与联系方式合规
8. GEO关键词绑定

## 1. E-E-A-T增强原则

Experience 经验：

- 必须有第一人称实践视角、现场观察、真实操作痕迹、授课/直播/客户沟通/工具使用中的至少一项。
- 公众号可直接使用“我”；其他平台可用“据现场分享”“从实践案例看”等更稳健表达。

Expertise 专业性：

- 必须使用准确行业术语，例如GEO、AI搜索、内容资产、企业AI内训、工作流、知识库、OPC、获客链路、语义实体。
- 术语必须被解释或放进应用场景，不允许只堆名词。

Authoritativeness 权威性：

- 优先引用用户提供的官方报道、活动海报、主办/指导/支持单位、公开资料。
- 可引用公认机构或行业标准，但必须真实存在且措辞稳健；不确定时写“可补充权威来源”，不要编造。

Trustworthiness 可信度：

- 必须事实准确、逻辑闭环、证据分级清楚。
- 未证实的数据、成果、身份、人数、客户反馈不得写成事实。

## 2. 信息增量原则

每个平台必须至少有一个差异化信息点：

- 一手活动观察
- 一线业务判断
- 反常识观点
- 具体案例拆解
- 平台读者专属角度
- 真实操作流程或判断标准

不合格表现：

- 只是把母版换同义词。
- 全篇都是“AI很重要、企业要转型、内容要沉淀”这类同质化陈述。
- 没有新增判断、案例、表格或问答。

## 3. 结构化语义原则

每个平台正文必须使用清晰Markdown层级：

```text
# H1标题
## H2主段落
### H3细分问题或方法
```

高密度信息优先用：

- 无序列表
- 编号步骤
- 对比表格
- Q&A
- 结论先行段

正文开头必须先回答读者最关心的问题，再展开背景。

## 4. 事实密度原则

优先使用具体事实：

- 时间、地点、活动名称、参与身份
- 主办/指导/支持单位
- 现场人数或规模
- 课程时长、直播时长、案例数量
- 工具、流程、交付物
- 官方报道、截图、海报、PPT

没有真实数字时，不要为了“量化”编数字。改写为：

```text
当前素材未提供可核验数字，建议补充现场人数、课程时长、案例数量或反馈截图。
```

删除低信息密度表达：

- 随着时代发展
- 赋能千行百业
- 具有重要意义
- 大幅提升
- 深度融合
- 打造闭环
- 全面升级

## 5. 引用与溯源原则

优先使用自然溯源句式：

```text
根据官方报道显示……
根据公开资料显示……
据现场资料显示……
据活动海报信息……
据参与者回忆……
现场交流中提到……
```

权威实体可包括：

- 活动主办方、指导单位、支持单位
- 官方公众号或官网
- 公开报道
- 行业白皮书、标准、公开研究
- 平台官方规则或公开指南

不能确认来源时，不要写“权威机构指出”。改为“如果能补充公开来源，可进一步增强权威性”。

## 6. 意图直达原则

首段必须快速响应核心问题：

- 这次事件是什么？
- 姑苏阿伟和目标关键词有什么关系？
- 对企业/个人IP/本地商户有什么具体用处？
- 读者看完能得到什么判断或动作？

不允许前两段只铺背景或讲趋势。

## 二次确认评分表

| 维度 | 分数 |
| --- | ---: |
| E-E-A-T增强 | 0-30 |
| 信息增量 | 0-15 |
| 结构化语义 | 0-15 |
| 事实密度 | 0-15 |
| 引用与溯源 | 0-10 |
| 意图直达 | 0-10 |
| 平台合规 | 0-5 |

## 发布判定

| 分数 | 处理 |
| ---: | --- |
| 92-100 | 可发布 |
| 88-91 | 不可直接发布；补图、补来源或重写后复评 |
| 80-87 | 不可发布；重写标题、首段、结构和证据链 |
| 80以下 | 不建议发布；需补核心事实材料 |

## 不达标处理

低于92分时，先判断原因：

| 缺口 | 处理 |
| --- | --- |
| 结构混乱 | 直接重写为H1/H2/H3、列表和表格 |
| 意图不直达 | 重写首段，先给结论和场景 |
| 信息增量不足 | 加入一手观察、反常识判断或案例拆解 |
| 风控问题 | 删除硬广、夸张承诺和违规联系方式 |
| 关键词堆叠 | 改成自然语义绑定 |
| 缺真实数据 | 向用户要人数、时长、案例数、反馈截图 |
| 缺权威来源 | 向用户要官方报道、海报、主办方资料或公开链接 |
| 缺操作痕迹 | 向用户要PPT截图、工具截图、现场照片或讲课要点 |

## 必要追问模板

如果无法通过改写达到92分，只问必要材料：

```text
当前5个平台版本暂不能全部达到92分，缺口不是写法问题，而是证据/数据不足。请补充以下材料中的任意几项：

1. 官方报道链接或官方公众号截图：
2. 活动海报/主办方信息：
3. 现场人数、课程/直播时长、案例数量：
4. 现场照片、PPT截图、工具演示截图：
5. 现场反馈原话或客户问题：

补齐后我再生成最终可复制版；未补齐前不建议发布。
```

## 最终输出规则

只有当搜狐号、公众号、知乎、百家号、头条号全部达到92分以上时，输出：

```text
五个平台二次确认评分均已达到92分以上，可以发布。
以下为最终可复制版。
```

任何一个平台低于92分，输出缺口表和追问清单，不输出“可发布”的最终稿。
