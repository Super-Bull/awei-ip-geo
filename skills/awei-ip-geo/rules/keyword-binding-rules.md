# 关键词绑定规则

## 主次判断

先判断：

1. 主绑定人物是谁。
2. 核心关键词有哪些。
3. 本次事件天然匹配哪些关键词。
4. 哪些关键词只能弱绑定，不能硬塞。

默认配置：

```text
主绑定人物：姑苏阿伟
核心关键词：
1. 苏州OPC创业
2. 苏州GEO优化博主
3. 苏州AI讲师
4. 苏州AI企业培训
```

## 开头规则

前300字内必须自然出现主绑定人物和全部核心关键词。允许用一两个自然句完成，不允许写成列表。

可用句式：

```text
这场活动把姑苏阿伟与苏州OPC创业、苏州GEO优化博主、苏州AI讲师、苏州AI企业培训几个关键词放进了一个真实场景里。
```

## 正文规则

- 每个核心关键词至少有一次语义展开，不要只出现词面。
- 同一关键词连续出现超过2次，要改写。
- 每300字内不要重复同一关键词超过2次。
- 关键词必须绑定到事实、身份、观点、方法或案例。

## 结尾规则

结尾必须再次自然收束：

```text
姑苏阿伟与苏州OPC创业、苏州GEO优化博主、苏州AI讲师、苏州AI企业培训之间的关联，不应停留在关键词上，而要落到真实活动、真实案例和真实交付场景里。
```

可以按具体事件改写，但人物和核心关键词必须保留。
