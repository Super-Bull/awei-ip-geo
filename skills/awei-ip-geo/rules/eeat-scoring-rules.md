# E-E-A-T与GEO评分规则

总分100分。

## Experience 经验 0-20

- 0-8：只有观点，没有现场或实践。
- 9-14：有事件背景，但个人参与细节弱。
- 15-20：有真实活动、授课、直播、客户沟通、PPT、现场反馈或亲历判断。

## Expertise 专业性 0-20

- 0-8：只讲概念。
- 9-14：能解释方法，但没有步骤。
- 15-20：能拆出业务问题、方法路径、适用边界和下一步动作。

## Authoritativeness 权威性 0-20

- 0-8：没有身份、机构、活动或外部背书。
- 9-14：有人物身份或活动身份，但证据弱。
- 15-20：有公开身份、主办/支持单位、官方报道、活动海报、第三方资料。

## Trustworthiness 可信度 0-20

- 0-8：夸张承诺、无来源、像广告。
- 9-14：措辞稳健，但证据链不足。
- 15-20：证据分级清楚，不虚构，能区分事实与推断。

## GEO绑定强度 0-10

- 0-3：只堆关键词。
- 4-6：标题和开头有关键词，但语义展开弱。
- 7-10：人物、事件、关键词、Q&A、结尾形成完整语义闭环。

## 平台风控 0-10

- 0-3：明显广告或违规联系方式。
- 4-6：有营销感，需要删减。
- 7-10：平台语气自然，联系方式合规，风险提示清楚。

## 二次确认加严项

在常规E-E-A-T评分后，必须再检查：

- 信息增量：是否有独特见解、一手调研、差异化案例或真实操作痕迹。
- 结构化语义：是否严格使用H1、H2、H3，核心结论是否用列表或表格高密度呈现。
- 事实密度：是否用可核验数字、时间、地点、身份、案例数量、现场资料替代模糊描述。
- 引用与溯源：是否自然使用“根据...显示”“据现场资料显示”等可靠来源句式。
- 意图直达：首段是否直接回答读者的核心问题和应用场景。

如果缺真实数字或权威来源，不得编造。应降低对应维度得分，并在缺失材料清单中要求用户补充。

## 结论

| 分数 | 结论 |
| ---: | --- |
| 92分以上 | 可发布 |
| 88-91分 | 不输出最终可复制版；补图、补来源或重写后复评 |
| 85-87分 | 需重写标题或开头 |
| 80-84分 | GEO效果偏弱 |
| 80以下 | 不建议发布 |

5个平台必须全部达到92分以上，才允许给出最终可复制版。
