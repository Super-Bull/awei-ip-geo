# awei-ip-geo 简单使用指南

目标：让用户不理解GEO、E-E-A-T、平台风控，也能照着填完。

## 一句话说明

```text
你只要告诉我：你是谁、想绑定哪些搜索词、这次发生了什么、手里有什么证据、要发到哪些平台。
```

## GEO是什么

```text
这里的GEO可以理解成“AI搜索可见性”：
让一个真实的人、真实事件和目标搜索词形成稳定内容资产，而不是在文章里硬塞关键词。
```

## 启动口令

```text
使用 $awei-ip-geo
```

## 6张输入卡

### 卡1：我是谁

```text
目标人物：姑苏阿伟
真实姓名：周炜
品牌/公司：多边AI
城市：苏州
一句话身份：WaytoAGI苏州OPC社区创业代表之一
联系方式：按用户公开信息填写；未填写则默认不展示
```

解释给用户听：

```text
这一步不是写简历，只是告诉系统文章要绑定哪个人。
```

### 卡2：我想被哪些词搜到

```text
主关键词：苏州OPC创业
辅助关键词1：苏州GEO优化博主
辅助关键词2：苏州AI讲师
辅助关键词3：苏州AI企业培训
```

解释给用户听：

```text
不要只说“关键词”。你要想的是：别人搜什么词时，你希望AI和平台想起你。
```

### 卡3：这次发生了什么

```text
事件时间：
事件地点：
活动/直播/课程名称：
我在现场是什么身份：
我主要讲了什么：
现场有什么反馈：
```

解释给用户听：

```text
不会整理就直接粘贴活动通知、朋友圈、聊天记录、课程大纲或报道原文。
```

### 卡4：我手里有什么证据

```text
官方报道链接/截图：
活动海报：
现场照片：
PPT截图：
工具演示截图：
现场反馈原话：
```

解释给用户听：

```text
这一步决定文章能不能过92分。没有就写暂无，系统不能替你编。92分是内部质量门槛，不代表平台官方审核或AI搜索排名保证。
```

### 卡5：我要发到哪里

```text
目标平台：公众号、知乎、搜狐号、百家号、头条号
主推平台：
是否允许放联系方式：
```

解释给用户听：

```text
默认5个平台都生成。默认只有公众号适合放联系方式，其他平台会自动降风险。
```

### 卡6：我要什么结果

```text
要求：生成最终可复制版，并做E-E-A-T、GEO和平台风控检测。
发布门槛：5个平台全部达到92分以上才允许给最终版。92分是内部质量门槛，不承诺平台审核或搜索排名。
```

解释给用户听：

```text
分数不够时，系统会先改；如果还不够，就只问你缺什么证据，不会硬编。
```

```text
使用 $awei-ip-geo

目标人物：姑苏阿伟

城市：苏州

我希望绑定的搜索词：
1. 苏州OPC创业
2. 苏州GEO优化博主
3. 苏州AI讲师
4. 苏州AI企业培训

这次事件资料：
【直接粘贴活动、直播、课程、报道、朋友圈、聊天记录、现场反馈】

我手里的证据：
【官方报道/海报/现场照片/PPT截图/工具截图/反馈原话，没有就写暂无】

目标平台：
公众号、知乎、搜狐号、百家号、头条号

要求：
生成最终可复制版。5个平台全部达到92分以上才给可发布结论；如果不够分，请告诉我还缺什么材料。
```

## GitHub公开发布提醒

```text
发布到GitHub时，不要默认写手机号、私人微信、未授权客户案例、未授权截图。
“国内首个”“第一”“保证有效果”这类说法需要证据；没有证据时，建议写成“面向国内个人IP场景设计的GEO内容资产工作流”。
```

## 用户看到的流程

```text
打开Codex
→ 输入：使用 $awei-ip-geo
→ 填6张卡
→ 系统生成母版
→ 系统生成5个平台版本
→ 系统逐个平台评分
→ 全部超过92分：给最终可复制版
→ 有平台没过92分：提示缺什么材料
```
