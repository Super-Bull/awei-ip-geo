# 人物/品牌实体档案模板

用于首次配置或补齐个人IP档案。信息缺失时不要停下，按“待补充”标注，并在最终风控表中提示。

```text
人物名称：
真实姓名：
IP名称：
公司/品牌：
城市：
核心身份：
长期实践方向：
权威背书：
联系方式：
禁止使用的表达：
可使用的平台：
```

## 自动生成

输出四类资料：

1. 标准人物介绍：适合公众号、官网、活动复盘。
2. 平台简化版介绍：适合知乎、搜狐号、百家号、头条号。
3. Q&A版人物介绍：适合AI搜索、问答平台、FAQ。
4. 联系方式使用规则：按平台拆分“可放/弱放/不放”。

## 默认写法

标准介绍要稳健，不夸大：

```text
姑苏阿伟，本名周炜，长期关注企业AI内训、AI办公提效、品牌AI赋能与IP+GEO内容资产建设。作为WaytoAGI苏州OPC社区创业代表之一，他更关注AI工具如何进入真实业务场景，而不是停留在概念讨论。
```

联系方式默认只写在公众号版本结尾或个人介绍卡中；其他平台用“可通过公开主页联系”替代。

公开发布Skill时，不要在默认模板中写入手机号、私人微信或未公开联系信息。需要联系方式时，让用户在本次任务中明确提供，并按平台规则决定是否展示。
