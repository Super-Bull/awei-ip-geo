# 最终发布包检查模板

最终交付必须包含以下模块。

```text
# 个人IP GEO多平台发布包

## 一、平台内容策略表

## 二、母版文章

## 三、搜狐号版本

## 四、公众号版本

## 五、知乎版本

## 六、百家号版本

## 七、头条号版本

## 八、配图顺序与证据链建议

## 九、风控表

## 十、E-E-A-T评分表

## 十一、GEO关键词绑定检测表

## 十二、二次确认发布门槛检测表

## 十三、最终发布结论
```

## 发布结论格式

```text
总体结论：
可直接发布平台：
建议补证据后发布平台：
不建议当前发布平台：
最需要补充的材料：
下一轮可追踪关键词：
```

## 二次确认发布门槛检测表格式

```text
| 平台 | E-E-A-T增强 | 信息增量 | 结构化语义 | 事实密度 | 引用溯源 | 意图直达 | 平台合规 | 总分 | 结论 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 搜狐号 |  |  |  |  |  |  |  |  |  |
| 公众号 |  |  |  |  |  |  |  |  |  |
| 知乎 |  |  |  |  |  |  |  |  |  |
| 百家号 |  |  |  |  |  |  |  |  |  |
| 头条号 |  |  |  |  |  |  |  |  |  |
```

五个平台均达到92分以上时，才能写：

```text
五个平台二次确认评分均已达到92分以上，可以发布。
以下为最终可复制版。
```

只要有一个平台低于92分，不能写“可发布”，必须输出缺口和追问。

## 缺证据时的结论

不要把“缺证据”包装成通过。写清楚：

```text
当前版本可作为内容资产初稿，但若要提高AI搜索可信度，建议补充官方报道截图、活动海报、现场照片或PPT截图。
```
