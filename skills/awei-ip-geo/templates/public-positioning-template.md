# GitHub公开发布定位模板

用于发布 `awei-ip-geo` 到GitHub、飞书文档、朋友圈或项目介绍页时使用。

## 推荐标题

```text
awei-ip-geo：面向国内个人IP和创业者的GEO内容资产生成 Skill
```

## 推荐一句话

```text
把一个真实的人、一次真实事件、一组目标搜索词，转成五个平台可发布、可追溯、可风控的GEO内容资产包。
```

## 推荐介绍

```text
awei-ip-geo 是一个面向国内个人IP和创业者的GEO内容资产生成 Skill。

它以姑苏阿伟在个人IP+GEO方向的持续实践为样本，把活动、直播、课程、报道、朋友圈、客户反馈等零散素材，整理成公众号、知乎、搜狐号、百家号、头条号五个平台内容包。

它不是普通AI写作提示词，而是一套从“人物实体 -> 关键词绑定 -> 事件证据链 -> 平台改写 -> E-E-A-T评分 -> 平台风控 -> 92分发布门槛”的内容资产工作流。
```

## 更有锋芒但稳妥的表达

```text
这是一个较早围绕“国内个人IP + GEO内容资产”场景系统化设计的开源 Skill，重点服务正在做个人品牌、企业服务、AI培训、OPC创业和本地业务获客的国内创业者。
```

## 适合谁

- 正在做个人IP的创业者
- AI讲师、企业AI培训顾问
- OPC创业者、本地服务者
- 想把活动、直播、课程、报道沉淀为内容资产的人
- 想在公众号、知乎、搜狐号、百家号、头条号建立一致人物实体的人

## 不适合谁

- 想靠关键词堆叠快速刷排名的人
- 没有真实事件、案例或证据链，只想编故事的人
- 想绕过平台审核或承诺AI搜索排名的人
