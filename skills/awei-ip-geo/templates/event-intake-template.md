# 事件资料输入模板

每次生成文章前，尽量让用户提供以下信息。用户没有全部提供时也可以继续生成，但必须标注证据强弱。

```text
事件时间：
事件地点：
活动名称：
主办/指导/支持单位：
参与身份：
现场人数：
核心主题：
我的分享内容：
现场反馈：
官方报道/第三方报道：
我希望绑定的关键词：
本次主推平台：
是否允许放联系方式：
是否有图片证据：
```

## 信息处理表

| 信息类型 | 处理方式 |
| --- | --- |
| 用户口述事实 | 写成“据活动资料显示”或“据参与者回忆” |
| 有官方报道 | 写成“根据官方报道显示” |
| 有现场图/海报 | 写成“据现场资料显示” |
| 没有证据的信息 | 降级为“现场交流中提到” |
| 夸张表达 | 自动改成稳健表达 |
| 联系方式 | 按平台规则自动删减 |

## 不足信息处理

- 没有时间：写“近日”或“在本次活动中”，不要编具体日期。
- 没有地点：写“在相关活动现场”，不要编城市或场馆。
- 没有人数：写“多位参与者”或“现场参与者”，不要编规模。
- 没有报道：不要写“媒体报道”“官方发布”；改为“据现场资料”或“据活动资料”。
