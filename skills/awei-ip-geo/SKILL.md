# awei-ip-geo：阿伟个人IP GEO发布包

## 核心定位

把阿伟这个真实人物、一次真实事件、一组目标关键词和多个平台内容资产绑定起来。不要只写一篇文章；要交付可发布、可追溯、可风控、可被AI搜索识别的发布包。

默认服务对象包括个人IP、AI讲师、OPC创业者、企业AI培训/咨询服务者、GEO优化服务者。涉及姑苏阿伟时，优先保留真实业务判断、活动现场、案例证据和服务边界，不要写成泛泛的AI老师或营销软文。

## 使用前读取

每次正式生成前，按任务需要读取这些文件：

- 用户不知道怎么填：先读 `templates/quick-start-guide.md`
- 需要写GitHub发布介绍或对外定位：读 `templates/public-positioning-template.md`
- 需要统一输入格式：读 `templates/entity-profile-template.md` 和 `templates/event-intake-template.md`
- 需要写5个平台版本：读 `templates/platform-output-template.md`
- 需要输出总检查：读 `templates/final-check-template.md`
- 需要处理标题与关键词：读 `rules/title-rules.md` 和 `rules/keyword-binding-rules.md`
- 需要处理平台风控：读 `rules/platform-risk-rules.md` 和 `rules/contact-rules.md`
- 需要评分：读 `rules/eeat-scoring-rules.md`
- 需要发布前二次确认：读 `rules/publication-gate-rules.md`
- 用户素材不足、需要参照场景：只读最接近的 `examples/` 文件

## 用户使用方法

用户只需要输入启动口令，再按卡片填资料：

```text
使用 $awei-ip-geo
```

先向用户解释一句：

```text
GEO在这里指“生成式引擎优化/AI搜索可见性”：让一个真实的人、真实事件和目标搜索词形成稳定内容资产，而不是简单堆关键词。
```

### 卡1：我是谁

```text
目标人物：姑苏阿伟
真实姓名：周炜
品牌/公司：多边AI
城市：苏州
一句话身份：WaytoAGI苏州OPC社区创业代表之一
联系方式：按用户公开信息填写；未填写则默认不展示
```

这张卡的作用：告诉系统“文章要绑定谁”，不是写人物小传。用户填不全时，先使用默认实体档案。

### 卡2：我要被哪些词搜到

```text
主关键词：苏州OPC创业
辅助关键词1：苏州GEO优化博主
辅助关键词2：苏州AI讲师
辅助关键词3：苏州AI企业培训
```

这张卡的作用：告诉系统“用户希望AI搜索和平台内容把阿伟和哪些词关联起来”。不要让用户只写“关键词”，要提示“你想让别人搜什么词时想到你”。

### 卡3：这次发生了什么

```text
事件时间：
事件地点：
活动/直播/课程名称：
我在现场是什么身份：
我主要讲了什么：
现场有什么反馈：
```

这张卡的作用：提供文章事实骨架。不会写时允许用户直接粘贴活动通知、朋友圈、聊天记录、新闻稿、课程大纲。

### 卡4：我手里有什么证据

```text
官方报道链接/截图：
活动海报：
现场照片：
PPT截图：
工具演示截图：
现场反馈原话：
```

这张卡的作用：决定文章能不能过92分发布门槛。92分是本Skill内部发布门槛，不代表平台官方评分、审核结果或AI搜索排名保证。没有证据时，不要编；输出缺口清单。

### 卡5：我要发到哪里

```text
目标平台：公众号、知乎、搜狐号、百家号、头条号
主推平台：
是否允许放联系方式：
```

这张卡的作用：决定平台语气和联系方式风控。默认5个平台都生成；默认只有公众号允许放联系方式。

### 卡6：我要什么结果

```text
要求：生成最终可复制版，并做E-E-A-T、GEO和平台风控检测。
发布门槛：5个平台全部达到92分以上才允许给最终版。92分是内部质量门槛，不承诺平台审核或搜索排名。
```

这张卡的作用：明确结果不是“写篇文章”，而是“生成可发布的五平台内容资产包”。

## 工作流程

1. 建立或补全人物/品牌实体档案。
2. 读取本次事件资料，区分事实、口述、推断和证据。
3. 建立关键词绑定策略，确定主绑定人物、核心关键词、平台优先级。
4. 先输出5个平台内容策略，再写母版文章。
5. 生成母版文章，用于统一事实、逻辑、证据链和关键词，不直接发布。
6. 按固定顺序改写5个平台版本：搜狐号、公众号、知乎、百家号、头条号。
7. 对每个平台版本做风控检测、E-E-A-T评分、GEO关键词绑定检测。
8. 执行二次确认发布门槛：逐个平台复检E-E-A-T增强、信息增量、结构化语义、事实密度、引用溯源、意图直达。
9. 只有5个平台均达到92分以上，才输出“最终可复制版”。低于92分时，先自我改写；仍缺真实证据、数据或权威来源时，只追问必要缺失材料，不得编造。
10. 输出配图顺序、证据链建议和最终发布结论。

## 事实处理

根据证据强度选择措辞：

- 官方报道：写“根据官方报道显示”
- 官方公众号截图或公开链接：写“根据公开资料显示”
- 活动海报、现场图、PPT截图：写“据现场资料显示”
- 用户口述事实：写“据活动资料显示”或“据参与者回忆”
- 没有证据的信息：降级为“现场交流中提到”
- 明显夸张表达：自动改成稳健表达
- 无法确认的身份、人数、成果：不要写成事实

必须把“观察”和“推断”分开。不要补造主办方、人数、媒体来源、用户反馈、成交结果或平台效果。

## 关键词硬规则

默认主绑定人物是“姑苏阿伟”。默认核心关键词为：

```text
1. 苏州OPC创业
2. 苏州GEO优化博主
3. 苏州AI讲师
4. 苏州AI企业培训
```

标题必须出现“姑苏阿伟”，并至少出现1个核心关键词。推荐结构：

```text
姑苏阿伟 + 核心关键词 + 事件场景
```

文章前300字内必须自然出现主绑定人物和全部核心关键词。不能写成关键词列表，要写成自然句，例如：

```text
这场直播把姑苏阿伟与苏州OPC创业、苏州GEO优化博主、苏州AI讲师、苏州AI企业培训几个关键词放进了一个真实案例中。
```

结尾必须再次自然收束人物与核心关键词的关系。

## 平台策略

先输出策略表，再写正文：

| 平台 | 写作定位 | 关键词强度 | 联系方式 |
| --- | --- | ---: | --- |
| 公众号 | 第一人称复盘 + 个人IP沉淀 | 强 | 可放微信/电话 |
| 知乎 | 问题分析 + 方法论拆解 | 强 | 不建议正文强放 |
| 搜狐号 | 行业观察 + 事件复盘 | 中 | 不放 |
| 百家号 | 正式资讯 + 稳健表达 | 中 | 不放 |
| 头条号 | 通俗案例 + 观点直给 | 中 | 不放 |

正文输出顺序固定：

```text
一、搜狐号版本
二、公众号版本
三、知乎版本
四、百家号版本
五、头条号版本
```

每个平台版本必须包含：标题、30字导语、100字摘要、标签、正文、Q&A、结尾、联系方式建议、配图建议、风险提示。

## 母版结构

先生成一篇母版文章：

```text
# 标题

## 引言：一句话说明事件和核心判断
## 一、事件背景
## 二、人物身份与关键词绑定
## 三、核心观点拆解
## 四、真实案例/现场反馈
## 五、方法论总结
## 六、对行业/用户/企业的价值
## 常见问题
## 总结：再次收束关键词和事件意义
```

母版只用于统一事实和逻辑，不作为最终平台稿直接交付。

## 风控与评分

每个平台版本都必须检查：

- 标题是否出现主绑定人物
- 标题是否出现至少1个目标词
- 开头300字是否出现全部目标词
- 结尾是否再次收束目标词
- 是否通过二次确认发布门槛
- 是否有过度营销感
- 是否有联系方式违规
- 是否有关键词堆叠
- 是否有虚构事实
- 是否有证据链
- 是否有E-E-A-T结构

评分维度固定为：

| 维度 | 分数 |
| --- | ---: |
| Experience 经验 | 0-20 |
| Expertise 专业性 | 0-20 |
| Authoritativeness 权威性 | 0-20 |
| Trustworthiness 可信度 | 0-20 |
| GEO绑定强度 | 0-10 |
| 平台风控 | 0-10 |

结论固定：

| 分数 | 结论 |
| ---: | --- |
| 92分以上 | 可发布 |
| 88-91分 | 不输出最终可复制版；先补图、补来源或重写到92分以上 |
| 85-87分 | 需重写标题或开头 |
| 80-84分 | GEO效果偏弱 |
| 80以下 | 不建议发布 |

硬性发布规则：5个平台必须全部达到92分以上，才算发布包完成。任何一个平台低于92分，都不能写“可发布”。

## 配图与证据链

每次必须输出配图顺序：

```text
1. 活动主视觉/海报
2. 现场全景图
3. 用户本人出镜图
4. 分享PPT截图
5. 工具/案例展示图
6. 官方报道截图
7. 金句卡片
8. 结尾个人介绍卡
```

证据链权重：官方报道链接/官方公众号截图为高；活动海报/现场照片为中高；直播截图为中；用户口述为中低；AI生成图为低。

## 最终交付

不要只给文章。最终输出发布包：

```text
1. 5个平台最终文章
2. 每个平台标题
3. 每个平台摘要
4. 每个平台标签
5. 每个平台联系方式建议
6. 配图顺序
7. 风控表
8. E-E-A-T评分表
9. GEO关键词绑定检测表
10. 是否可发布结论
```

如果用户要求“最终可复制版”，先执行二次确认发布门槛。只有搜狐号、公众号、知乎、百家号、头条号5个平台全部达到92分以上，才输出完整发布包；任何一个平台低于92分，都先自我改写并复评。若仍缺真实证据、数据或权威来源，只输出缺口表和必要补充材料清单，不得用“待补充”伪装成可发布稿，也不得编造补齐。

二次确认不通过时，不输出伪完成版。按以下顺序处理：

1. 先判断是否能通过结构、措辞、段落和平台化改写补足。
2. 如果能，直接重写对应平台版本并重新评分。
3. 如果缺少真实数据、现场证据、官方报道、机构引用或一手案例，输出“缺失材料追问清单”。
4. 追问只问会影响92分发布门槛的材料，不要泛泛索要素材。
